安装前必读 - 成都建工 V3.1
==============================

本安装程序将在以下位置部署：
  • 主程序:   C:\Program Files\ChengduConsole\成都建工控制台.exe
  • 启动脚本: C:\Program Files\ChengduConsole\windows_scripts\
  • 业务源码: C:\Program Files\ChengduConsole\source_code\
  • 嵌入式 Python: C:\Program Files\ChengduConsole\runtime\python\
  • 模型运行时: C:\Program Files\ChengduConsole\models\local-llm\runtime-win-cpu-x64\

请确认：
  1. 已安装 Microsoft Visual C++ 2015-2022 Redistributable (x64)
  2. 已安装 Microsoft Edge WebView2 Runtime（系统托盘 UI 需要）
  3. 安装目录有写入权限（约 1.2 GB）

继续即表示同意以下条款：
  • 应用程序使用本地便携 PostgreSQL，数据库文件位于：
        {localappdata}\ChengduConstructionConsole\database\
    （数据库用户数据保存在系统用户目录，不在安装目录内，
      这样升级和卸载不会丢失数据。）
  • 应用程序不会主动连接外网，所有 AI 推理均在本地完成。
  • 安装后第一次启动会下载/校验大模型权重（约 2.5 GB）；
    如需离线部署，请提前将 GGUF 模型放入：
        {app}\models\local-llm\
