## 三、 详细任务分解

### P0-① CpuFeatureDetector.cs

**目标**：防止老旧 CPU 执行 AVX2 编译的 `llama-server.exe` 导致 `0xC000001D` 崩溃闪退。

**文件路径**：`desktop_apps/windows/Services/CpuFeatureDetector.cs`

**代码骨架**：
```csharp
using System.Runtime.InteropServices;

namespace ChengduConstructionController.Services;

public static class CpuFeatureDetector
{
    private const int PfAvx2InstructionsAvailable = 40;

    [DllImport("kernel32.dll")]
    private static extern bool IsProcessorFeaturePresent(int processorFeature);

    public static bool SupportsAvx2() { ... }

    public static string ResolveLlamaServerExecutable(string runtimeDirectory) { ... }
}
```

**集成点**：`WindowsServiceAdapter.BuildLocalModelStartInfo()`

---

### P0-② WebView2Detector.cs

**目标**：适配 Win10 LTSC 非管理员账户场景，防止 HKLM 注册表检测失败。

**文件路径**：`desktop_apps/windows/Services/WebView2Detector.cs`

**代码骨架**：
```csharp
namespace ChengduConstructionController.Services;

public static class WebView2Detector
{
    private const string WebView2ClientKey = @"{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}";

    public static bool IsInstalled() { ... }    // HKCU 优先，HKLM 保底
    public static void InstallSilently(string bootstrapperPath) { ... }  // --per-user
}
```

---

### P0-③ PostgreSQL 动态端口协商

**重构目标**：`ServiceOrchestrator.EnsurePostgresRunning()`

**改动点**：
1. 替换 `cmd.exe /c 00_START_POSTGRES.bat` 为 C# 原生 `ProcessStartInfo`
2. 使用 `ProcessInspector.GetListeningProcessIds()` 扫描可用端口
3. 启动参数使用 `-c "port=<port>"` 覆盖配置，**不写磁盘**
4. `WindowsServiceAdapter.BuildPythonStartInfo()` 中动态注入 `DATABASE_PORT` 环境变量

---

## 四、 验收标准

| 任务 | 验收条件 | 测试场景 |
|---|---|---|
| P0-① | 老旧 CPU 启动时自动回退到 SSE4.2 版本或不报错退出 | 赛扬/奔腾机器 |
| P0-② | 非管理员账户下 WebView2 检测正常，静默安装成功 | Win10 LTSC 普通用户 |
| P0-③ | 54320 被占用时自动切换到 54321~54369，Python 服务正常连接 | 端口冲突环境 |
| P1-④ | 连续崩溃服务触发指数退避，5 次后熔断并报警 | 服务异常反复重启 |
| P1-⑤ | 目标机无需安装 Node.js，前端正常访问 | 离线 Windows 机器 |
| P2-⑥ | 嵌入式 Python 目录可独立运行，无 pip install 依赖 | 断网环境 |
