🍏 macOS 专享 · 稳定双通道

macOS 专版套件

日常使用的 Chrome/Edge 免端口直连，或系统内置 Safari 极简零依赖。

  • 日常浏览器直连：免开 9222 调试端口，直接使用当前已登录账号
  • 独立副驾视窗：后台自动处理，全程保持不抢占打字焦点
  • Safari 纯原生零依赖：系统自带 AppleScript 驱动，无需安装插件
  • POSIX 内核锁托管：防多进程争夺，18 项跨平台测试全部通过
macOS 增强版 (.zip) 支持 Chrome / Edge Safari 原生版 (.zip) 0 外部依赖 · 系统自带
🪟 Windows 官方推荐 · 纯原生 CDP

Windows 原生专版套件

纯原生 Node.js 18+ 驱动，0 个 npm 外部依赖包，彻底告别后台插件掉线。

  • 0 npm 依赖包：无需运行 npm install，秒级直接冷启动
  • 0 浏览器插件：无需在 Edge/Chrome 安装任何外部插件
  • 内置双击即开 BAT：双击 start_edge_cdp.bat 即开即用
  • 系统内核锁保护：msvcrt 文件锁保护，会话状态持久化
Microsoft Edge 专版 (.zip) 系统自带 · 双击秒开 Google Chrome 专版 (.zip) 纯原生 CDP 直连
