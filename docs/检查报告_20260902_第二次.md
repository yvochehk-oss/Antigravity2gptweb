## 五、TAX ↔ RAG 协作架构

架构完整且正确：

```
Document
    ↓
RAG ingest
    ↓
canonical_facts（仅 RAG 可写入）
    ↓
analytics_canonical_facts_current（视图）
    ↓
TAX 只读消费者（各 service）
```

**关键保证**：

- RAG 是 canonical_facts 的唯一写入方
- TAX 对 canonical_facts 零写入权限
- 所有 legacy 表冻结为只读审计源
- Phase 3 退役：8 条 POST 路径 → 410 Gone
- 三重溯源：fact version + algorithm version + report version
