# 时间维度

## 基本信息

- dimension_id: time
- version: 1.0
- name_cn: 时间
- name_en: Time

## 定义

用于分析的时间周期维度。

## 时间层级

- 年度：年份，如 2026
- 季度：年-季度，如 2026-Q1
- 月度：年-月份，如 2026-08
- 周次：年-周次，如 2026-W33
- 日期：具体日期，如 2026-08-18

## 财务周期

建筑行业通常使用：

- 财政年度：1月1日 - 12月31日
- 税务申报周期：季度申报
- 项目周期：按项目合同约定

## 使用场景

- 回款率趋势分析
- EAC 预测追踪
- 成本偏差分析
- AI Review 历史对比
