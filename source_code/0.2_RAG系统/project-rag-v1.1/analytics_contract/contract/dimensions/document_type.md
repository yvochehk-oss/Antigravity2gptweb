# 文档类型维度

## 基本信息

- dimension_id: document_type
- version: 1.0
- name_cn: 文档类型
- name_en: Document Type

## 定义

合同及履约相关文档的分类。

## 文档类型

- CONTRACT - 合同：主合同文件
- SUPPLEMENT - 补充协议：合同变更/补充
- VARIATION - 签证：设计变更/现场签证
- MEETING - 会议纪要：重要会议记录
- INVOICE - 发票：收款/付款发票
- PAYMENT - 付款凭证：付款申请/银行回单
- SETTLEMENT - 结算：进度结算/竣工结算
- QUALITY - 质量资料：验收记录/检测报告
- SAFETY - 安全资料：安全检查记录
- OTHER - 其他：其他文档

## 使用场景

- ProjectRAG 文档检索过滤
- AI Review 证据收集
- 文档完整性检查
