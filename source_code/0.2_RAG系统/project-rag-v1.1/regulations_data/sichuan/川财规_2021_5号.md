> 四川省残保金征收实操口径，是四类实体（总包/建材/劳务/设备）
> 都涉及的费用合规项。

## 关键条款（3 条）

### 第一条

第一条　为规范残疾人就业保障金（以下简称“保障金”）征收使用管理，促进我省残疾人就业，根据《残疾人保障法》《残疾人就业条例》《四川省＜中华人民共和国残疾人保障法＞实施办法》《财政部 国家税务总局 中国残疾人联合会关于印发＜残疾人就业保障金征收使用管理办法＞的通知》（财税〔2015〕72号）、《财政部关于取消、调整部分政府性基金有关政策的通知》（财税〔2017〕18号）等规定，结合我省实际，特制定本实施办法。

### 第二条

第二条　保障金是为保障残疾人权益，由未按规定安排残疾人就业的机关、团体、企业、事业单位和民办非企业单位（以下简称“用人单位”）缴纳的资金。

### 第三条

第三条　四川省范围内保障金的征收、使用和管理，适用本实施办法。
