> 四川省增值税起征点的具体数额，是判定小规模纳税人起征点
> 与个体工商户纳税义务的关键依据。

## 关键条款（2 条）

### 第一条

一、按期纳税的，为月销售额20000元。

### 第二条

二、按次纳税的，为每次（日）销售额500元。
以上政策自2016年5月1日起执行。
