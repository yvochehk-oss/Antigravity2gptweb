## 一、 成都市工程起重机械租赁税收审核 3 大要件

### 1. 特种设备安装告知与安拆资质
塔吊、施工升降机属于建筑特种设备。承租方施工企业与租赁公司签订合同时，必须附带特种设备检验合格报告和起重设备安装工程专业承包资质。涉及安装拆卸作业并收取安拆费的，安拆服务应按**建筑安装服务（9% 或 3%）**开具发票。

### 2. 机械台班运转签证记录
租赁双方每月结算时，必须由施工项目部机械管理员、安全员、机手三方签署《工程机械台班运转月度确认单》（载明工作天数、起止时间、实际台班数）。无真实台班记录的大额机械租赁费发票，税务机关将重点核查是否存在虚增项目成本偷漏企业所得税行为。

### 3. 财产租赁合同印花税申报
设备租赁合同属于财产租赁合同，双方均应按租赁金额的 **千分之一 (0.1%)** 在四川省电子税务局按期申报缴纳印花税。
