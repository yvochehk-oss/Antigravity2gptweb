## 一、 成都市建材商贸纳税评估 4 大核心审核指标

成都市税务机关在对建材商贸企业进行税收风险巡查与纳税评估时，重点穿透核验：

### 1. 存货周转率与进销配比合理性
- 检查当期钢材、水泥的采购品类、规格、吨位是否与向下游建筑施工企业销售的品种数量高度吻合；
- 严查是否存在“大额进项开具钢材、销项却开具劳务或其他杂项”的变异开票行为。

### 2. 物流与电子过磅单据完整性
- 必须提供真实的运费结算发票或大宗物资配送电子过磅单（载明：发货单位、收货项目名称、运输车号、毛重、皮重、净重、司磅员签名及过磅时间）；
- 无实物过磅单与物流凭证支撑的大额建材进项税额，一律暂缓抵扣并移交稽查部门。

### 3. 银行资金结算流水
- 必须实现公对公银行结算，货款支付人必须与购销合同买方完全一致；
- 严查资金当天到账当天转入私人账户或关联包工头账户的“资金一日游”回流特征。

### 4. 买卖合同印花税申报
- 按照买卖合同金额的 **万分之三 (0.03%)** 在四川省电子税务局按期申报缴纳印花税。
