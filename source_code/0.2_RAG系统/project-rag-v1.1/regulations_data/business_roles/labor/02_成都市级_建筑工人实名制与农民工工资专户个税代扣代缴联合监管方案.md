# 【成都市级】建筑工人实名制与农民工工资专户个税代扣代缴联合监管方案

> **文件依据**：成都市住建局、成都市人社局、成都市税务局联合监管方案  
> **适用层级**：成都市地方行政与税收协同监管细则  
> **适用业务角色**：在成都市从事工程分包与用工管理的劳务公司 (labor 业务角色)、总承包企业 (construction 业务角色)  
> **企业映射**：实际适用企业由 Canonical Entity Master 按 business_role 映射，不将业务角色当作法人。
> **核心概念**：建筑工人实名制门禁考勤、工资专户银行代发、全员全额个税申报比对

---

## 一、 建筑工人“实名制+专户代发”闭环

1. **成都市建筑工人实名制管理系统**：
   所有进入成都市施工现场的劳务作业人员，必须通过人脸识别或实名打卡门禁系统记录进出场施工考勤；
2. **农民工工资专用账户管理**：
   总承包企业设立农民工工资专用账户，建设单位按月足额拨付人工费用至专户；劳务公司编制经工人签字确认的月度考核工资表，由开户银行直接将工资打入工人个人银行卡（严禁现金发放或包工头代领代发）。

---

## 二、 成都市税务局“个税与工资专户”比对模型

成都市税务机关通过“自然人电子税务局 (ITS)”与“成都市住建实名制平台”实时联网比对：

```
住建实名制考勤人数/天数 ──┐
                         ├──> 税务比对引擎 ──> 判定虚列工资 / 隐瞒用工偷漏个税
银行专户实发工资流水   ──┘
```

### 常见预警与处罚情形：
1. **“大头小尾”或拆分虚构工资**：为规避 5,000 元/月 个税起征点，将大额劳务报酬拆分至未在现场务工的虚假人员身份证上，一经查实定性为偷税，追缴个税并处 0.5~5 倍罚款；
2. **未依法全员全额明细申报**：劳务企业未按月向成都市主管税务机关报送现场施工人员工资薪金个税明细扣缴申报表的，纳税信用等级直接降级为 D 级，并暂停其在成都市的建筑施工投标与分包资质。
