# 成都建工 · 天府掌舵 —— iPhone 沉浸式 PWA 高管专享指南

本文档指导集团董事长及高管如何在 iPhone 上将「天府掌舵」配置为独立全屏 App，享受与原生 iOS 应用毫无二致的高奢黑金体验。

---

## 📱 一、为什么 iPhone 推荐使用 PWA？

通过 Safari 的 PWA（Progressive Web App）特性，iPhone 可以直接将系统固化为桌面独立应用，具备以下优势：

1. **100% 原生全屏沉浸（无浏览器边框）**：
   - 自动隐去 Safari 顶部的网址栏、前进/后退箭头及底部工具栏。
   - 纯净全屏展示集团经营大盘与 360° 穿透图谱。
2. **高奢黑金【建】字高清晰图标**：
   - 自动加载内置的 180×180 高清 `apple-touch-icon.png` 黄金徽标，整齐陈列在 iPhone 主屏幕。
3. **刘海屏与灵动岛（Dynamic Island）完美避障**：
   - 基于 `viewport-fit=cover` 与 `env(safe-area-inset-top)` / `env(safe-area-inset-bottom)` 动态计算，顶部黑金状态栏与底部手势条（Home Indicator）严丝合缝。
4. **离线高管快照（飞机/高铁模式可用）**：
   - 自动缓存最近一次穿透底账，无移动信号时仍可秒开查阅 26 家法人与工程毛利。

## 🚀 二、三步一键添加到 iPhone 主屏幕

### 第一步：在 iPhone Safari 中打开系统
在 iPhone 的 **Safari 浏览器** 中访问系统地址（支持局域网 IP 或远程 Cloudflare 安全穿透地址）：
> 例如：`https://xxxx.trycloudflare.com` 或 `http://192.168.1.3:5173`

### 第二步：点击 Safari 底部“分享”按钮
在 Safari 屏幕底部的工具栏中间，点击 **【分享】** 图标（带有向上箭头的方形方块 ⎋）。

### 第三步：选择“添加到主屏幕”
1. 在弹出的菜单列表中向下滑动，找到并点击 **【添加到主屏幕】(Add to Home Screen)**；
2. 应用名称默认为 **`天府掌舵`**，图标自动展示黑金【建】字；
3. 点击右上角的 **【添加】**。

🎉 **完成！** 您的 iPhone 桌面上将立即出现「天府掌舵」专属高管 App，点击即可秒开全屏运行！

## ⚡ 三、iPhone 专享特性配置说明

| 特性 | 技术规范 | 体验提升 |
| :--- | :--- | :--- |
| **全屏独立运行** | `display: "standalone"` | 启动后无任何浏览器 URL 栏与底部菜单，100% 原生应用感 |
| **状态栏透明融合** | `apple-mobile-web-app-status-bar-style: black-translucent` | 顶部状态栏与深空黑金渐变浑然一体 |
| **触控与防误触** | `-webkit-tap-highlight-color: transparent` | 消除网页点击灰色阴影，触控更精准自然 |
| **页面防双击缩放** | `user-scalable=no, viewport-fit=cover` | 快速连击卡片与图表时不发生意外缩放 |
| **AI 智策灵动岛** | VisionOS 风格悬浮居中 Dock | 底部导航居中高亮，支持实时流式打字与快速发问 |

## 🛡️ 四、网络连接与远程穿透模式

* **办公室 / 集团内网直连**：
  手机连接集团 WiFi，直接访问内网服务器地址（如 `http://192.168.1.x:5173`）。
* **出差 / 移动 4G/5G 远程直连**：
  进入「天府掌舵」底部的 **【穿透设置】**，粘贴 Cloudflare 远程加密安全隧道 HTTPS 地址，一键保存即可在任意网络下安全访问集团底账。
