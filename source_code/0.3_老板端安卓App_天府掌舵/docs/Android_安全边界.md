# Android 安全边界

## 当前工程保证

- Release 通过 `network_security_config.xml` 只信任系统证书并拒绝明文 HTTP；Debug 单独允许明文流量和用户证书，仅供本地联调。
- `allowBackup=false`，同时用备份/数据迁移规则排除文件、数据库、偏好设置和外部目录。
- Release 开启 R8 优化、混淆和资源收缩；这些措施增加逆向成本，但不等于保护嵌入 APK 的秘密。
- Capacitor 禁止混合内容、正式 WebView 调试和生产日志；本地页面使用 HTTPS scheme。
- 正式签名只读取 `CDJG_RELEASE_*` 环境变量。keystore、口令、Token 和服务端密钥不得提交到 Git。

## 必须由服务端保证

- 每个 API 都要验证身份、角色、企业、项目与字段权限；客户端传来的角色或企业 ID 不可信。
- 财税计算和风险规则在服务端执行，并返回可审计的版本、时间和证据引用。
- Token 短期有效、可撤销、可轮换；敏感操作需要二次确认或更强认证。
- 限流、审计、异常检测、数据脱敏和下载水印不能只在 App 中实现。

## App 不得保存或输出

- 签名私钥、数据库密码、Cloudflare/API 服务端密钥；
- 明文登录口令、长期 Token、完整身份证号/银行卡号；
- 未经过期和字段裁剪的整库离线副本；
- 包含敏感底账、提示词、Token 或用户隐私的调试/崩溃日志。

## 发布边界

Debug APK 可以用于开发者真机和局域网联调，不能发给管理层作为正式版本。正式版本必须使用受控 keystore 签名、完成 Release 安全验收，并通过受管理的应用商店或企业分发渠道交付。
