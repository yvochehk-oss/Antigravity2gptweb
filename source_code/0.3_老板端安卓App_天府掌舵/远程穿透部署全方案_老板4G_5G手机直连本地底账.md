# 成都建工·天府掌舵 —— 远程非局域网（4G/5G 移动网络）直连方案

本指南专门解决 **“老板在外部出差、工地现场、高铁飞机上使用手机 4G/5G 网络，如何穿透直连公司/本地电脑的真实数据库与 AI 引擎”** 的核心诉求。

---

## 🌐 核心架构原理

```text
[老板安卓手机 (4G/5G 漫游)] 
       │ 
       ▼ (全局 HTTPS 银行级加密传输)
[Cloudflare 全球边缘网络 / 穿透专线]
       │
       ▼ (穿透办公室内网与路由器防火墙，无需公网IP，无需映射端口)
[本地计算机 (Mac / Windows)]
  ├── AI 财税智控系统 (FastAPI · Port 8921)
  ├── RAG 知识库与高管移动网关 (FastAPI · Port 8922)
  └── PostgreSQL 真实底账数据库 (58张发票 / 30份合同 / 188份凭据)
```

---

## 🚀 三种纯远程（非局域网）连接方案

### 方案一：Cloudflare 零信任安全穿透（⭐ 强烈推荐 · 免费 · 零配置）

**为什么最推荐？**
* **无需公网 IP**：即使公司电脑处于移动/电信大内网、多层路由器之后，依然能秒级打通；
* **无需路由器开端口**：完全杜绝黑客扫描端口的安全隐患；
* **全自动 HTTPS 证书**：数据经过银行级 TLS 1.3 传输加密，防止财务数据外泄。

#### 操作步骤：
1. **本地电脑端启动穿透**：
   * **Mac**：在 `0.3_老板端安卓App_天府掌舵/` 目录下运行 `./start_cloudflare_tunnel.sh`
   * **Windows**：双击 `start_cloudflare_tunnel_windows.bat`
2. **获取专属远程安全链接**：
   * 终端会自动输出一条加密链接，例如：`https://chengdu-boss-xxxx.trycloudflare.com`（或绑定企业固定专属域名）；
3. **老板手机端填入并连接**：
   * 打开手机 App，点击底部「穿透设置」；
   * 将链接填入「后端服务地址」并保存；
   * 顶部状态栏即刻显示 **`🟢 5G 远程加密直连 · 全网在线`**！
4. **固定永久域名（进阶）**：
   * 在 Cloudflare 免费添加自定义域名（如 `boss.cdjg-ai.com`），隧道启动后域名永不变更，老板手机一次配置终身免维护。

---

### 方案二：Tailscale 点对点加密专网（⭐ 适合董事长专机）

**特点**：点对点 WireGuard 虚拟内网，安全级别最高。

1. 在本地电脑安装 [Tailscale](https://tailscale.com/) 并登录；
2. 在老板安卓手机上安装 Tailscale App 并登录同一账号；
3. 电脑会分配一个永久固定的虚拟 IP（例如 `http://100.88.99.10:8922`）；
4. 老板手机 App 填入该 IP 后，无论身在世界任何地方，手机只要开机即可自动走加密隧道直连本地电脑。

---

### 方案三：FRP / 轻量云服务器反向代理（企业自建云通道）

**特点**：通过企业现有的阿里云/腾讯云服务器进行流量转发。

1. 在云服务器部署 `frps`（监听端口 7000）；
2. 在本地电脑运行 `frpc`，将本地 `8922` 端口映射至云服务器的域名 `https://api.yourcompany.com`；
3. 老板手机 App 默认固定填写该域名即可。

## 🔒 离线应急与高管隐私保障

1. **离线快照缓存（无信号自动降级）**：
   * 当老板处于飞机飞行模式或地下车库无 4G/5G 信号时，App 会**自动启用离线快照引擎**，照常查看最近一次同步的完整大盘、各项目成本与 26 家法人底账。
2. **高管防窥隐私遮罩**：
   * 点击右上角眼睛图标，所有真实金额瞬间变为 `¥ ***,***`，防止在公众场合被旁人窥视敏感财务数据。
3. **生物识别安全锁**：
   * 支持开启手机自带指纹 / 人脸识别解锁，手机遗失也不会泄露集团机密。
