### Mac 启动
进入：
`01_当前完整系统_V0.1/chengdu_construction_tax_system_v0_1/`

执行：
`./run_demo.sh`

或双击：
`run_demo_mac.command`

访问：
`http://127.0.0.1:8765`

### 注意
- Demo 默认 SQLite；生产建议 PostgreSQL。
- API Key 不保存在数据库，仅通过环境变量注入。
- 税务规则须经专业人员复核后才可用于正式申报。
- AI 只做检查、解释、建议和复核，不覆盖确定性税务、利润和 EAC 计算。
