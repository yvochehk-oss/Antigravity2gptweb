# V2.1 企业试运行深化

## 新增闭环
1. 合同台账：收入、材料、劳务、设备、专业分包。
2. 发票台账：销项/进项、税率、可抵扣标记、项目归属。
3. 银行流水：收款/付款、项目和交易对手归属。
4. 履约证据：材料验收、劳务结算、设备台班。
5. 成本科目树：材料/劳务/设备/分包/项目管理/税费。
6. 月度法人税务台账：A/B/C/D分别核算。
7. 月结锁与审计：生产版必须启用。

## 编号边界
系统内固定 A施工、B劳务、C商贸、D设备租赁；系统外固定 甲劳务、乙设备、丙材料、丁专业分包/其他。
