# 项目财税筹划沙盘 V2.1

## 两层口径
1. L1 全生态筹划：26家系统内单位 + 系统外单位共同参与合同、发票、税务、履约、资金与风险分析。
2. L2 系统内穿透：仅26家系统内单位做内部交易抵销，穿透到系统边界外的真实成本、真实税务现金与管理利润。

## 职责边界
- AI：只能在确定性引擎已验证的候选方案中提出推荐、解释取舍和风险。
- 确定性引擎：金额分配、容量硬约束、成本穿透、税务现金估算、评分和项目利润重算。
- RAG：提供法规和合同证据，不直接写入会计事实。

## API
`POST /api/projects/{pid}/allocation-planning/recommend`

核心输入：业务类型、待规划净额、目标、系统内比例上下限、可选偏好比例、候选主体、主体覆盖参数。

> `package_amount` 必须是尚未计入 real_costs 的待规划净额，避免重复成本。规划税务金额是基于现有台账/发票的估算，不替代法定申报。
