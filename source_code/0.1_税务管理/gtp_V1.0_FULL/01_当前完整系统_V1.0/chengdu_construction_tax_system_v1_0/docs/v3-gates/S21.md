Task21 starts Phase H writer cutover without switching readers or RAG.

## Required Phase-1 state

- `writer_mode = SHADOW`
- `LEGACY_WRITE = ON`
- `NEW_FACT_WRITE = OFF` for the official synchronous writer
- post-commit shadow projection is enabled through the cutover service
- `RAG_SOURCE = LEGACY`
- `NEW_FACT_READ = SHADOW`
- `legacy_frozen = false`

## Safety contract

1. Legacy official write commits before shadow projection starts.
2. Shadow projection runs in an isolated savepoint.
3. Shadow failure records `V3_SHADOW_WRITE_FAILED`; it never rolls back legacy success.
4. MATCH is resolved automatically; MISMATCH/ERROR enters `review_diff_queue` through a PostgreSQL trigger.
5. `operation_key` makes shadow evidence idempotent.
6. No automatic transition to DUAL_WRITE or V3_PRIMARY.
7. RAG remains legacy-sourced in Task21; reader/RAG cutover belongs to Task22.
