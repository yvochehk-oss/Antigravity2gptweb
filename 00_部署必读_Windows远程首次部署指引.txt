# 成都建工 V3.0 · Windows 远程生产部署全流程指引

本文档适用于将系统部署到全新的 Windows 计算机（支持 Windows 10/11 / Windows Server 2016+，推荐 x64 CPU，支持 AVX2 指令集，16GB+ 内存）。

---

##  部署包架构与已包含资源

本打包文件已预先配置好 Windows 原生多进程架构，并已**内嵌最新生产数据库底账与切片文件**：

1. **数据库与切片文件**（位于 `database/`）：
   * `projectrag_latest.dump`：PostgreSQL 二进制备份（包含 123 张表、491 条全文切片、473 份源文档及 30 条核心事实）；
   * `projectrag_latest.sql`：纯文本 SQL 备份（备用）；
   * `restore_database_windows.bat`：一键 UTF-8 建库与 pgvector 还原批处理工具。
2. **业务与前后端源码**（位于 `source_code/`）：
   * `0.1_税务管理`：核心财税与鉴权引擎；
   * `0.2_RAG系统`：知识中台、事实路由与高管网关；
   * `0.3_老板端安卓App_天府掌舵`：移动端驾驶舱与 Copilot 问答（已编译至 `static_dist`）；
   * `0.4_IDP文档录入引擎_V3.0`：工程资料穿透录入与审计中心。
3. **离线工具箱**（位于 `windows_scripts/tools/`）：
   * 内置极速包管理器 `uv.exe`、.NET 运行库安装脚本等。
4. **AI 模型策略（免打包，本地一键下）**：
   * 按照要求，**未携带任何大型模型权重文件**；
   * 采用 **讯飞星火 Spark-X2.5-4B (Q4_K_M)** 作为默认本地大模型，配套 **BGE-M3** 向量检索模型。

---

##  部署步骤（新机 4 步极速落地）

### 第一步：解压与目录准备
将本压缩包解压至目标电脑任意磁盘（建议路径简单、不含空格和中文，例如 `D:\cdjg_v3` 或 `E:\073_成都建工`）。

---

### 第二步：一键配置 Python 运行环境
目标电脑**无需预先手动安装和配置 Python**！

1. 进入 `windows_scripts` 目录；
2. 双击运行 **`06_SETUP_ENV.bat`**（或 `06_一键配置Python314环境.bat`）；
3. 脚本将自动调用内置的 `uv.exe` 自动下载并配置官方标准的 Python 3.12 稳定运行内核，并通过国内加速源安装所需依赖包（通常 1~2 分钟即可完成）。

---

### 第三步：一键还原 PostgreSQL 数据库与切片
系统内置开箱即用的绿色便携版 PostgreSQL（位于 `database\pgsql`，默认端口 `54320`，已集成 `pgvector` 扩展），**目标电脑无需单独安装外部 PostgreSQL 数据库**！

1. 确认数据库正在运行（启动脚本 `windows_scripts\00_START_POSTGRES.bat` 会自动守护拉起便携版 54320）；
2. 双击运行 **`database\restore_database_windows.bat`**（或 `windows_scripts\07_一键还原PostgreSQL数据库.bat`）；
3. 根据提示确认端口与用户名（默认回车即可，自动优先连接 54320 便携版）：
   * 脚本会自动使用 **UTF-8 编码 (`-E UTF8 -T template0`)** 建立 `projectrag` 数据库，避免中文乱码；
   * 自动启用 `vector`、`btree_gist`、`pgcrypto`、`pg_trgm` 四大扩展；
   * 自动将 `projectrag_latest.dump` 中的表结构、切片与事实数据还原到位；
   * 还原完成后会自动输出 `chunks`、`documents`、`facts` 数量校验。

---

### 第四步：一键下载 AI 本地模型 (星火 Spark-X2.5-4B + BGE-M3)
目标电脑联网状态下：

1. 双击运行 **`windows_scripts\05_一键下载AI模型_国内魔搭.bat`**；
2. 下载器将通过国内高速镜像源（ModelScope 阿里魔搭 / HF-Mirror）自动完成三项下载：
   * `[1/3]` 部署兼容 Spark 架构的 Windows CPU x64 推理引擎 `runtime-win-cpu-x64\llama-server.exe`；
   * `[2/3]` 高速下载 **星火 Spark-X2.5-4B** 主模型文件 `models\local-llm\Spark-X2.5-4B-Q4_K_M.gguf` (~2.6GB)；
   * `[3/3]` 高速下载 **BGE-M3** 全文向量检索模型至 `models\bge-m3`。
3. 下载完成后终端提示 ` AI 模型依赖已准备完毕！`。

---

### 第五步：一键启动全系统与控制台

您可以通过以下任意一种方式启动和管理成都建工 V3.0 系统：

* **方式 A（图形窗口控制台，强烈推荐）**：
  * 直接双击根目录 **`成都建工控制台.exe`**；
  * 窗口直观呈现 5 大微服务卡片、健康状态指示灯、端口与 PID，支持一键启动全部、一键重启、一键停止与浏览器访问；
  * 本程序已采用自包含发布打包，**无需安装任何 .NET 运行时**即可直接运行。

* **方式 B（轻量系统托盘控制台）**：
  * 双击根目录 **`START_TRAY_WINDOWS.bat`**（或 `成都建工V3.0托盘控制台.exe`）；
  * 系统在屏幕右下角任务栏托盘中常驻运行，右键菜单支持一键启停、状态探测与实时大模型推理控制台查看。

* **方式 C（命令行批处理脚本）**：
  * 双击项目根目录下的 **`START_WINDOWS.bat`**（或 `windows_scripts\00_一键启动全部服务.bat`）。

启动后，系统将自动按顺序拉起各大后台服务，并在就绪后自动在默认浏览器中打开老板端驾驶舱：

| 服务序号 | 服务名称 | 监听端口 | 核心功能说明 |
| :---: | :--- | :---: | :--- |
| **0** | **PostgreSQL** | 54320 / 5432 | 统一底账与向量切片库 |
| **1** | **本地大模型 (星火 Spark)** | 8930 | Spark-X2.5-4B 本地离线推理与 Copilot 问答 |
| **2** | **RAG 事实证据中台** | 8922 | 高管驾驶舱聚合网关、四流事实校验与切片检索 |
| **3** | **IDP 穿透式录入引擎** | 8933 | 凭证资料结构化解析与智能审计录入 |
| **4** | **税务管理中台** | 8921 | 税务底账、发票申报、统一身份鉴权与 Token 刷新 |
| **5** | **老板端 Web 移动驾驶舱** | 5173 | 董事长/总经理移动驾驶舱与 AI Copilot 交互界面 |

* **税务管理中台 Web**：`http://127.0.0.1:8921`
* **默认管理员账号**：`admin` / 密码：`888888`
* **默认业务操作员**：`operator` / 密码：`888888`
* **一键停止全系统**：双击根目录 **`STOP_WINDOWS.bat`**（或 `windows_scripts\99_停止全部服务.bat`）即可干净释放所有端口与进程。
