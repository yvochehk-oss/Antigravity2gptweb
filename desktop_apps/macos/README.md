# 成都建工控制台（macOS）

这是一个使用 macOS 原生 `MenuBarExtra` 的菜单栏应用，显示在 macOS 右上角，不显示程序坞图标。菜单栏入口由系统负责在内屏、外接屏和主屏切换时自动布局；应用不会读取或修改菜单栏坐标。

## 构建与运行

在当前目录执行：

```bash
./scripts/build_app.sh
open "build/成都建工控制台.app"
```

应用会按以下顺序寻找 V3.0 根目录：

1. `CHENGDU_PROJECT_ROOT` 或 `CDJG_PROJECT_ROOT` 环境变量；
2. 已保存的项目目录；
3. 应用包或当前目录的父级目录中，同时包含 `start_all.sh` 和 `stop_all.sh` 的目录；
4. 如果仍未找到，可在菜单中选择项目目录。

## 菜单功能

- 显示总体状态、本地语言模型、税务系统、资料与知识系统、文档录入引擎、老板驾驶舱状态；
- 每 5 秒检查一次本机健康接口；
- 本地语言模型同时检查健康接口、已加载模型列表、`.local_llm.pid` 与 `llama-server` 进程命令；老板驾驶舱使用项目根目录 `.app.pid` 记录受控前端进程，并核对命令、工作目录和项目归属；
- 打开税务系统、资料与知识系统、老板驾驶舱本地页面；
- 启动全部、重启全部、停止全部业务服务和老板驾驶舱；停止操作保留 PostgreSQL；
- 查看控制台日志、设置登录后自动运行、退出控制台。

核心服务仍只调用项目已有的 `start_all.sh start` 与 `stop_all.sh`，不会自动安装依赖、下载模型或执行迁移。老板驾驶舱优先使用本地 `dist` 的 Vite 预览；没有构建产物时使用已安装的本地 Vite 开发服务，不调用 `npm`/`npx`。停止前必须确认 PID、命令、工作目录和 Boss 目录归属，无法确认时不会发送信号。控制台退出时业务服务继续运行。

应用运行不需要在线字体、在线服务或额外运行时依赖。日志只记录控制台动作和结果，不记录脚本输出。
