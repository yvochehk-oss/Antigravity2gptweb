## 👥 双脑协作架构与执行时序

本项目采用创新的 **双平面隔离架构 (Dual-Plane Architecture)**：将“思考与代码修改权”交给云端大模型，将“确定性测试与客观证据收集”交给本地桌面环境。

### 协作流程图

```mermaid
sequenceDiagram
    autonumber
    actor User as 👤 开发者 / 客户
    participant LocalAgent as ⚡ 本地桌面 Agent (Antigravity/Cursor)
    participant GPTWeb as 🧠 ChatGPT 网页版 (云端顶尖大脑)
    participant LocalEnv as 💻 本地真实运行环境

    User->>LocalAgent: 自然语言下发需求
    LocalAgent->>GPTWeb: 注入本地上下文与任务意图
    activate GPTWeb
    Note over GPTWeb: 深度架构推演 & 方案拆解
    GPTWeb->>LocalEnv: 通过隧道插件直接读写本机文件
    GPTWeb-->>LocalAgent: 发送验证指令 (TEST: ... EXPECTED: ...)
    deactivate GPTWeb
    activate LocalAgent
    Note over LocalAgent: 任务前快照已就绪，比对文件清单核对变更
    LocalAgent->>LocalEnv: 运行本地真实构建与测试命令
    LocalEnv-->>LocalAgent: 捕获真实 Exit Code、stdout 与 stderr
    LocalAgent->>GPTWeb: 回传客观执行日志进行终审 (task-review)
    deactivate LocalAgent
    activate GPTWeb
    Note over GPTWeb: 审查真实测试结果
    alt 测试全部通过
        GPTWeb-->>LocalAgent: 裁决 APPROVED (闭环达成)
        LocalAgent-->>User: 交付完成报告
    else 存在异常或未通过
        GPTWeb->>LocalEnv: 原地修复，自动触发下一轮验收
    end
    deactivate GPTWeb
```

### 角色分工与执行铁律

| 角色 | 核心职责 | 行为边界（严禁越位） | 带来的好处 |
| :--- | :--- | :--- | :--- |
| 🧠 **ChatGPT 网页版**<br>*(云端总架构师)* | 负责深度逻辑推演、方案拆解、**通过隧道插件直接读写本机工作目录中的业务文件**、提供测试命令与审核测试结果 | 仅操作用户授权的本机工作目录，独占方案与代码修改权 | 借助网页端顶尖推理能力，保证全局架构与业务代码的高水准 |
| ⚡ **本地桌面 Agent**<br>*(精准验收执行端)* | 负责提取环境上下文、任务前快照与文件清单基线、核对落盘变更、运行真实测试命令、将测试日志回传 GPT 审查 | **严禁越俎代庖编写或覆盖本地业务代码**；GPT 声称完成但零文件变更时直接判 BLOCKED | 用真实环境提供可复核的客观证据，彻底杜绝 AI 幻觉和瞎编 |

## 🚀 驱动通道与加固特性

统一版只保留三条经过实战验证的驱动通道，并内置以下加固机制：

1. **Safari 原生驱动（macOS）**：
   - 纯 AppleScript 直驱日常已登录的 Safari，复用现有登录态，系统自带 0 扩展 0 依赖；
   - Tab 精确绑定 + 跨进程事务锁，避免多任务串话与误投递。
2. **Chromium CDP 驱动（macOS / Windows）**：
   - macOS 使用 Python 驱动（`chrome_chatgpt.py`），Windows 使用 Node.js 原生引擎（`chrome_chatgpt.js`，0 npm 依赖包）；
   - 以独立持久化数据目录拉起浏览器（Windows 双击 `start_edge_cdp.bat` / `start_chrome_cdp.bat`），ChatGPT 登录态长期保存，绝不与日常浏览器进程冲突；
   - 严格等待 React 水合就绪（`isContentEditable === true`），通过原生 CDP 物理点击 `button[data-testid="send-button"]`，彻底解决 ProseMirror 多行长文本误插入换行的问题；
   - 提交成功判据为“DOM 中实际出现匹配预期内容的 User 消息节点”，绝非仅依赖按键事件返回。
3. **跨平台 P0 级文件锁与状态隔离**：
   - POSIX / macOS 平台使用 `fcntl.flock`，Windows 原生平台使用 `msvcrt.locking`；
   - 锁文件统一存放于 `tempfile.gettempdir()`，生命周期由操作系统内核管理，进程异常中断自动释放，彻底避免死锁；各驱动熔断器使用独立状态文件，互不影响。
4. **增强型凭据脱敏**：
   - 过滤覆盖 Cookie、Authorization、Basic Auth、带用户名密码的 URI，全面守护企业资产。

### 独立终端快速运行

#### 🍏 macOS 快速启动

* **方式 A：Chrome CDP 版（Chromium 家族通用）**
  ```bash
  git clone --depth 1 https://github.com/yvochehk-oss/Antigravity2gptweb.git chatgpt-web-reasoner

  ```

  ```bash
  python3 scripts/safari_chatgpt.py --help
  ```

## 🛡️ 安全合规与隐私保障

1. **自动敏感凭据脱敏**：
   内置自动化安全正则扫描引擎，所有提交与回传日志中的 API Key（如 `sk-...`）、授权 Token 会被自动转换为掩码（`[OPENAI_KEY]`），确保任何敏感凭据绝不泄露到网络中。
2. **快照 + 清单双重防覆盖机制**：
   每个任务开始前自动给工作目录做快照并记录文件清单（sha256）。GPT 声称完成但清单零变更时直接判 BLOCKED；任何一轮改坏可用 `orchestrate.py restore` 从任务前快照恢复，绝不让错误改动无声覆盖开发者已写好的业务代码。
3. **完全所有权**：
   用户始终拥有对本地工作目录与运行环境的绝对控制权，代码只存储在您的本地机器中。
